# Inscribed Squares on Spheres and Hyperbolic Planes: A Dynamical Systems Approach

**Author:** Zitong Shen  
**Status:** Preprint (Completing arXiv submission)

## Abstract

This paper provides the first complete solution to the generalization of the classical Toeplitz inscribed square problem to two-dimensional constant curvature spaces. We prove that on any smooth strictly convex closed curve in the two-dimensional sphere $S^2$ or the hyperbolic plane $H^2$, there exist four points forming an inscribed square. The core of our proof introduces a novel topological dynamical systems framework. Through careful analysis of the geometric properties of convex curves, we first establish crucial geometric lemmas that guarantee the well-definedness and key properties of the "rotation map" $R$. This map moves points along the curve while preserving specific geometric relations. By analyzing the fourth iterate of this map, we transform the existence problem for inscribed squares into a fixed point problem for a circle homeomorphism. Finally, employing classical rotation number theory combined with a rigorous homotopy argument, we prove the necessary existence of such fixed points. This framework successfully unifies the treatment of both positive curvature (spherical) and negative curvature (hyperbolic) geometries, revealing the profound topological nature of this problem.

**Keywords:** Inscribed square, Toeplitz conjecture, convex curve, hyperbolic geometry, spherical geometry, dynamical systems, rotation number, fixed point.
